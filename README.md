# JobPath — Assessment 2 final candidate

An original educational job-search interface based on the user's SEEK usability evaluation and JobPath V4 wireframe concept. **Not affiliated with SEEK; all listings are fictional.**

## Open the project
1. Extract the ZIP completely.
2. Open `index.html` in Chrome or Edge, or run it with VS Code Live Server.
3. `PREVIEW.html` is a standalone file containing the same HTML, CSS and JavaScript for easier previewing.

## Technology choices
- **Semantic HTML5**: `header`, `nav`, `main`, `section`, `aside`, `article`, `footer`, labelled inputs and native dialogs.
- **CSS Grid**: two-column filters/results layout and responsive grids; media queries stack content on mobile.
- **Flexbox**: navigation, card metadata and button groups.
- **Vanilla JavaScript**: filtering, sorting, saved jobs, job details and two-role comparison; no backend or data collection.
- **Accessible interaction**: native controls, keyboard focus, screen-reader status, reduced motion and larger targets.

## Source files
- `index.html`: semantic page and interactive elements
- `styles.css`: responsive styles and explanatory comments
- `script.js`: fictional data and commented interaction functions
- `Figma link`: Figma Link
- `TECHNICAL_RATIONALE_DRAFT.md`: approx. 200-word rationale

## Important limitations
This is a candidate, **not a certified WCAG-compliant or fully tested production website**. Search uses fictional data; Save persists only until page refresh; Apply is not a real application workflow. The design follows the earlier JobPath V4 wireframe concept, not an independently verified exported Figma file.
